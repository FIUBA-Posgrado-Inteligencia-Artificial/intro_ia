## Materiales obligatorios

En este módulo, vamos a adentrarnos en el área que más se ha desarrollado con éxito dentro de la Inteligencia Artificial, llamada **Aprendizaje Automático**. Como vimos en la historia de la IA, el éxito de esta área se debe a la capacidad de las máquinas para aprender de datos y mejorar su rendimiento sin necesidad de programación explícita, lo que ha permitido avances significativos en una variedad de aplicaciones como el reconocimiento de voz, la visión por computadora y la predicción de patrones.

### Tutorial de Scikit-Learn

Aprovechemos que estamos introduciéndonos en Aprendizaje Automático para presentar una de las librerías más conocidas del tema, llamada **[Scikit-Learn](https://scikit-learn.org/stable/)**. Esta librería ofrece **herramientas simples y eficientes** para el análisis de datos y la construcción de modelos de Machine Learning, tanto para principiantes como para expertos, facilitando tareas como clasificación, regresión y clustering. Nos proporciona una amplia gama de funciones que facilitan el desarrollo **de todas las etapas del ciclo de vida** de Machine Learning.

Veamos en la siguiente notebook una introducción a esta librería para familiarizarnos con sus primeras funciones, las cuales exploraremos con mayor profundidad en módulos y asignaturas posteriores:

- 📓 [Scikit-Learn - Jupyter Notebook](./content/jupyter_notebooks/01%20-%20scikit-learn.ipynb)
